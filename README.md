# Network-Investigation-Casebook

What happens when a simple network discovery turns into a full system compromise?

This project explores that question through a hands-on investigation of an intentionally vulnerable machine in an authorized virtual lab.

But I wasn't only interested in **how** the system was compromised.

I wanted to understand:

> **What role did human decisions and security practices play in making the compromise possible?**

### Tools Used

- Kali Linux
- Bettercap
- Nmap
- Metasploitable 2

### Investigation

The investigation covered:

- Network discovery
- Service enumeration
- Authentication testing
- Vulnerability research
- Controlled exploitation
- Privilege analysis
- Human-factor analysis

The investigation uncovered several weaknesses that eventually led to full system compromise.

But the technical attack was only half the story.

**The other half was the human factor.**
