# Case ID #
NIC-001
(Port Investigation Casebook — Case 001)


## Case Type ##
Controlled network security investigation.

## Environment ##
Kali Linux → Investigation Machine

Metasploitable 2 → Intentionally vulnerable target

## Authorization ##
This investigation was tested in an isolated personal network lab using an intentionally vulnerable machine. No authorized systems were tested.

## Case Title ##
Network Investigation: Exposed Services, Weak Authentication, and Remote Compromise.

## Investigation Summary ##
This case documents a controlled investigation of an intentionally vulnerable network system. The investigation focused on identifying exposed services, examining authentication weaknesses, researching vulnerable software versions, and determining whether these weaknesses could lead to unauthorized access and system compromise.

## Key Outcome ##
The investigation identified exposed network services, weak authentication, and a vulnerable FTP service. Controlled testing demonstrated that these weaknesses could be used to obtain unauthorized access and achieve privileged access to the laboratory system. The investigation also examined the potential confidentiality and integrity impact of the compromise.
